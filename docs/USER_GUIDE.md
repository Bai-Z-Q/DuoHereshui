# 个人医疗管家 - 使用手册

## 欢迎使用个人医疗管家

个人医疗管家是一个智能化的健康管理助手,通过对话的方式帮助您管理用药、查询药品信息、检查用药安全。本手册将指导您如何使用系统的各项功能。

## 快速上手

### 第一次使用

1. **访问系统**
   - 打开浏览器访问前端页面(如 http://localhost:8080)
   - 您将看到欢迎界面和系统功能介绍

2. **完善个人档案**
   - 点击右上角的"👤 个人档案"按钮
   - 填写您的基本信息:
     - 姓名、年龄、性别、体重
     - 慢性病史(如有)
     - 过敏史(非常重要!)
     - 特殊人群标识(孕妇、哺乳期等)
   - 点击"保存档案"

> ⚠️ **重要提示**: 完善个人档案能帮助系统更准确地进行用药安全检查,特别是过敏史信息非常关键。

## 核心功能使用指南

### 1. 症状咨询与用药推荐

当您感到不适时,可以直接向系统描述症状。

**使用步骤:**

1. 在输入框中描述您的症状
   - 例如:"我头痛,已经两天了"
   - 例如:"发烧38度,还咳嗽"
   - 例如:"皮肤过敏,很痒"

2. 系统会询问更多细节:
   - 症状持续时间
   - 严重程度
   - 是否有其他伴随症状

3. 根据您的症状,系统会:
   - 评估症状严重程度
   - 推荐合适的非处方药
   - 提供用法用量建议
   - 给出相关注意事项

**示例对话:**

```
用户: 我头痛,有什么药可以吃?
助手: 我理解您有头痛的症状。请问:
     1. 头痛已经持续多久了?
     2. 疼痛程度如何?(1-10分)
     3. 是持续性疼痛还是阵发性?

用户: 持续了两天,大概6分的痛感
助手: 根据您的症状,以下是可能适合的非处方药:
     
     1. 布洛芬
        适用于: 缓解轻至中度疼痛...
        用法: 一次0.2g,一日2-3次...
     
     2. 对乙酰氨基酚
        适用于: 缓解头痛...
        用法: 一次0.3-0.6g...
```

**紧急情况识别:**

如果您描述的症状包含以下关键词,系统会立即提示您就医:
- 剧烈头痛、胸痛、呼吸困难
- 意识模糊、昏迷
- 严重过敏反应
- 大量出血

### 2. 药品信息查询

想了解某种药品的详细信息时使用此功能。

**使用方法:**

**方法一: 通过对话查询**
- 直接说:"查询布洛芬的信息"
- 或:"布洛芬有什么副作用?"

**方法二: 通过药品查询功能**
1. 点击侧边栏的"💊 药品查询"按钮
2. 在搜索框输入药品名称
3. 点击"搜索"
4. 从搜索结果中选择想了解的药品
5. 查看详细信息

**药品详情包含:**
- 📋 商品名称
- 🏷️ 药品类型(处方药/非处方药)
- ✅ 适应症(治疗什么症状)
- 📝 用法用量
- ⚠️ 副作用
- 🚫 禁忌症
- 💡 注意事项
- 📦 储存方式

### 3. 用药安全检查

在服用任何药品前,建议进行安全检查。

**使用步骤:**

1. 在药品详情页面点击"进行安全检查"按钮
   或直接说:"检查布洛芬的安全性"

2. 系统会根据您的健康档案检查:
   - ✓ 是否与过敏史冲突
   - ✓ 是否与正在服用的其他药品有相互作用
   - ✓ 是否有禁忌症
   - ✓ 特殊人群是否适用

3. 查看安全检查结果:
   - 🔴 高风险警告: 严格禁止使用
   - 🟡 中度风险提示: 需要特别注意
   - 🟢 低风险提醒: 一般注意事项

**示例结果:**

```
🔍 安全检查结果
总体评估: ⛔ 存在风险,请注意

风险详情:
🔴 高风险警告
类别: 过敏风险
说明: 您对青霉素过敏,该药品禁忌症中提到相关成分,请勿使用!

建议:
• 存在高风险,请勿使用该药品
• 建议咨询医生或药师
```

### 4. 用药记录管理

帮助您记录和管理正在服用的药品。

**添加用药记录:**

1. 点击侧边栏的"📋 用药管理"
2. 填写用药信息:
   - 药品名称
   - 开始日期
   - 结束日期(可选)
   - 剂量(如:一次1片)
   - 频率(如:每日3次,饭后服用)

3. 保存后系统会:
   - 记录您的用药情况
   - 在安全检查时考虑药物相互作用
   - (未来版本)提供用药提醒

**查看用药记录:**
- 在用药管理页面查看所有活跃的用药记录
- 可以停用已经不再服用的药品

## 最佳使用实践

### 描述症状的技巧

为了获得更准确的推荐,描述症状时请包含:

1. **主要症状**: 具体哪里不舒服
   - ✓ 好:"头部右侧疼痛"
   - ✗ 不够具体:"不舒服"

2. **持续时间**: 症状出现多久了
   - ✓ 好:"已经两天了"
   - ✓ 好:"从昨晚开始"

3. **严重程度**: 对您的影响
   - ✓ 好:"疼痛感6-7分,影响睡眠"
   - ✗ 不够具体:"有点疼"

4. **伴随症状**: 其他不适
   - ✓ 好:"头痛,还有点发烧"
   - 帮助系统更全面分析

### 安全用药提示

1. **首次使用新药前务必进行安全检查**
2. **及时更新个人健康档案**,特别是:
   - 新发现的过敏
   - 新的慢性病
   - 正在服用的新药物

3. **严格遵守用法用量**
   - 不要自行增加剂量
   - 注意服药时间(饭前/饭后)
   - 注意药品间隔时间

4. **观察身体反应**
   - 如出现不适,立即停药
   - 记录副作用情况

5. **定期就医检查**
   - 系统不能替代医生
   - 慢性病需要定期复查
   - 严重症状及时就医

## 注意事项与免责声明

### ⚠️ 重要提示

1. **本系统不能替代医生**
   - 提供的信息仅供参考
   - 不能进行疾病诊断
   - 不能开具处方药

2. **以下情况请立即就医**
   - 症状严重或持续加重
   - 出现紧急症状(胸痛、呼吸困难等)
   - 服药后出现严重副作用
   - 慢性病需要调整用药

3. **用药安全**
   - 仔细阅读药品说明书
   - 不要超量服用
   - 注意药品保质期
   - 儿童、孕妇、老年人用药需特别谨慎

4. **隐私保护**
   - 您的健康信息加密存储
   - 不会与第三方共享
   - 可随时修改或删除个人信息

### 紧急联系方式

- **急救电话**: 120
- **中毒急救**: 120
- **医疗咨询**: 建议联系您的家庭医生

## 系统限制

目前系统的限制包括:

1. **只推荐非处方药(OTC)**
   - 不提供处方药建议
   - 处方药需要医生开具

2. **药品数据库**
   - 包含常用药品信息
   - 可能不包括所有药品
   - 定期更新中

3. **智能程度**
   - 基于规则的症状匹配
   - 无法处理复杂病情
   - 建议尽可能详细描述症状
